# English text for the Reading page

These files are the **World English Bible** (WEB), which is in the public domain, in the JSON form published by
https://github.com/TehShrike/world-english-bible. The Reading page shows it only when the learner taps
"Show English". The Hebrew verse numbers are matched to the English with the KJV note that the Open Scriptures
Hebrew Bible puts on verses whose numbering differs. To use another translation later, replace these files and
the small reader in scripts/build-reading.mjs; the app itself only receives plain verse text.
